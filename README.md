# KAFU Smart Lost & Found

A web-based platform designed to help the Kaimosi Friends University (KAFU) community report, search for, and recover lost items on campus.

🌐 **Live Website:** https://kafu-smart-lost-found.onrender.com/

## About the Project

Losing personal belongings on campus can be stressful. KAFU Smart Lost & Found provides a central place where students and other members of the university community can report missing items and share information about items they have found.

## Features

- **Report Lost Items:** Submit details about items that have gone missing.
- **Report Found Items:** Share information about items found on campus.
- **Search Reports:** Search reports to help match lost items with found items.
- **Claims:** Access the claims section for item recovery.
- **Recent Activity:** View recent lost-and-found activity.
- **Web Access:** Access the platform through a web browser.

## Technology Stack

- Python
- Flask
- SQLite
- HTML and CSS

## How to Use

1. Visit the live website.
2. Submit a lost-item or found-item report.
3. Search existing reports for a possible match.
4. Follow the available claims process to pursue recovery.

## Project Goal

To make lost-item reporting and recovery easier, more organized, and more accessible within the KAFU community.
